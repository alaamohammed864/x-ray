# مرآة الأشعة السينية — مشروع Android يعمل دون إنترنت (الإصدار 1.1.0)

واجهة محلية داخل WebView عبر `WebViewAssetLoader` على أصل HTTPS محلي. عند بناء APK ينزّل GitHub Actions مكتبة MediaPipe Tasks Vision 0.10.14 وملفات WASM ونموذجي الوجه واليد ويضمّنها داخل APK. بعد التثبيت لا يحتاج التطبيق إلى الإنترنت (ولا يطلب إذن INTERNET).

## ما الذي أُصلح في هذا الإصدار

| المشكلة | الأثر | الإصلاح |
|---|---|---|
| مسار التحميل في `MainActivity` كان يفتح `www/www/index.html` | صفحة فارغة / 404 عند تشغيل التطبيق | تحميل `/assets/index.html` (المعالج يستلم المسار بعد حذف `/assets/`) |
| زاوية ميلان الرأس تُحسب من العينين بعد قلب المرآة | **النموذج كله مقلوب 180° في الوضع الافتراضي** | الميلان من محور الجبهة←الذقن على الشاشة |
| تدوير/تحجيم يُطبَّق على نقاط الوجه نفسها | عيون وفك وأسنان تنزاح عن الوجه، وتضاعف أثر منزلق الحجم (s²) | الجمجمة والدماغ فقط في إطار الرأس، وبقية الطبقات تُرسم مباشرة على نقاط التتبع |
| إزاحة `jawOpen` تُضاف فوق نقاط تتحرك أصلاً مع الفك | الفك يبتعد عن الذقن الحقيقية | الفك يتبع النقاط مباشرة؛ `jawOpen` يظهر كنسبة |
| لا معالجة لتنزيل `blob:` داخل WebView | زر التسجيل لا يحفظ شيئاً | جسر `AndroidBridge.saveVideo` يحفظ في `Movies/XRayMirror` |
| إيقاف الكاميرا عند الخلفية دون استئناف | بعد العودة يبقى التطبيق عالقاً على «متوقف مؤقتاً» | إيقاف/استئناف من الـActivity والصفحة معاً |
| عدسة الأشعة تبقى في آخر موضع بعد اختفاء اليد | عدسة «شبح» | تُصفَّر عند فقدان اليد + رسالة إرشاد |
| عظم الإبهام المشطي (1→2) مفقود وكان يُرسم 0→1 | توزيع العظام غير دقيق | 8 رسغ + 5 مشط + 14 سلامية = 27 |
| Android 15 (targetSdk 35) يرسم تحت أشرطة النظام | الترويسة تحت شريط الحالة | مسافات من `WindowInsets` |
| `buildToolsVersion` الافتراضي 34 بينما يثبّت الـWorkflow الإصدار 35 | احتمال فشل/تنزيل إضافي أثناء البناء | تثبيت `35.0.0` |
| أي تنقل خارجي ممكن داخل WebView | تعريض الجسر لصفحات غير محلية | حجب كل تنقل خارج الأصل المحلي |

## الميزات

- تتبع الوجه واليدين (GPU ثم CPU احتياطياً) مع تنعيم وتناوب الكاشفين لتخفيف الحمل.
- الرأس: جمجمة، دماغ (نصفان + مخيخ تخطيطي)، محجرا العينين مع القزحية، عضلات الوجه، أوعية، **فك سفلي** مع مفصل الفك، **10 أسنان لكل قوس** على خط الشفتين الداخلي، و**عضلات حركة العين الست** تخطيطياً.
- اليد: 27 عظمة وأوتار ومحيط.
- وضع أفقي 16:9 أو عمودي 9:16، عدسة تتبع السبابة، شفافية الكاميرا، وتسجيل 10 ثوانٍ.

## بناء APK

1. أنشئ مستودع GitHub جديداً.
2. ارفع **محتويات** مجلد `XRayMirrorAndroid` إلى جذر المستودع (يجب أن يظهر `app/` و`.github/` في الجذر).
3. افتح Actions ← `Build X-Ray Mirror APK` ← Run workflow.
4. نزّل Artifact باسم `XRayMirror-Android-APK` وثبّت `app-debug.apk`.

الـWorkflow يفشل صراحةً إذا: كان حجم أي نموذج أصغر من 1MB، أو غاب ملف WASM، أو وُجد رابط خارجي في الصفحة، أو طُلب إذن INTERNET، أو لم تكن النماذج والمكتبة داخل APK الناتج.

## ما تم التحقق منه وما لم يُتحقق منه

**تم التحقق منه فعلياً (في بيئة التطوير):**
- صياغة JavaScript، ووجود كل عناصر الواجهة التي يستدعيها الكود.
- تشغيل الصفحة في Chromium بوجه ويد **اصطناعيين**: الاتجاه الصحيح مع المرآة وبدونها، الميلان، فتح الفم، الوضعان (أشعة/ملون)، العدسة، وتخطيط الهاتف العمودي — بلا أخطاء JavaScript.
- تحميل مكتبة MediaPipe 0.10.14 وملف WASM الحقيقيين محلياً، وأن غياب النموذج يُعرض كرسالة خطأ واضحة مع بقاء زر البدء.
- منطق الإيقاف/الاستئناف مع كاميرا وهمية.
- ترجمة `MainActivity.java` بنجاح مقابل `android.jar` (API 34).

**لم يُتحقق منه بعد — يحتاج تجربة على هاتفك:**
- بناء Gradle نفسه على GitHub (لم أستطع تشغيل Gradle هنا).
- دقة المحاذاة مع **وجه ويد حقيقيين** (استخدمتُ إحداثيات اصطناعية؛ النماذج الحقيقية لم تكن قابلة للتنزيل في بيئتي).
- طلب إذن الكاميرا، الأداء وFPS، تفعيل GPU على جهازك، وحفظ التسجيل في المعرض.
- إزاحة الجمجمة عند تدوير الرأس يميناً ويساراً وأعلى وأسفل مبنية على قواعد تقريبية من النقاط وتحتاج ضبطاً بالتجربة.

## حدود يجب معرفتها

- الرسومات تعليمية ثنائية الأبعاد/شبه ثلاثية الأبعاد فوق نقاط التتبع، وليست مجسماً طبياً ثلاثي الأبعاد.
- الجمجمة والدماغ نموذج عام لا يطابق جمجمة الشخص؛ الفك والأسنان والعضلات تمثيلات تخطيطية.
- التطبيق محاكاة بصرية تعليمية، وليس أشعة حقيقية أو أداة تشخيص.

## تشخيص الأعطال على الهاتف

- نسخة debug تسمح بفحص الصفحة عبر `chrome://inspect` على الحاسوب.
- سجلات الصفحة تظهر في Logcat بالوسم `XRayMirror`.
- إذا ظهرت «تعذر تحميل ملفات التتبع المحلية» فالـAPK بُني دون خطوة تنزيل النماذج؛ أعد البناء من Actions.
